# AI Coding Maturity Governance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the repo-local AI coding governance baseline from "strong Level 3 / partial Level 4 / conditional Level 5" toward full Level 5 readiness.

**Architecture:** Keep the runtime untouched. Add repo-local governance artifacts: agent-readable GitHub issue forms, CODEOWNERS, fast CI, governance-change CI, branch-protection documentation, and static tests that prevent future drift.

**Tech Stack:** GitHub Actions, GitHub issue forms, CODEOWNERS, PowerShell static checks, existing Node/Python test commands, Superpowers planning.
