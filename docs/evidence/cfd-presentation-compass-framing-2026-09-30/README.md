- 拖曳時羅盤跟著旋轉、以及拖曳期間查詢頻率的上限：自動化的合成拖曳沒有轉動串流相機；串流 iframe 與父頁不同來源，父頁讀不到羅盤的 `data-heading`／`data-reads`。單元測試已涵蓋上限（回覆延遲 400 ms、拖曳 2 s 送出 2 次），真站需人工拖曳確認。
- Kit log 中的框取結果紀錄（`LoadingManager: framed the building after CFD overlay composition.`）未取回。
- 其他模型（沒有外殼群組、或沒有基地元素）上的框取行為未在真站測試；單元測試涵蓋退回順序。
