# 半透明表面壓力

## 範圍

使用者要求保留建築外觀，同時判讀建物表面壓力。於已宣告 `surface_pressure` 的結果圖層加入透明度滑桿與 0.35 / 1.00 快捷值，沿用 `overlay_style`。先顯示壓力層，再調整透明度；僅 Kit 對同一 prim 的讀回可顯示已套用。

不修改結果 artifact、BIM 材質、壓力值、求解域、網格或 credentials；不新增 API。半透明只能改善遮擋，不能修復計算外殼的幾何精度。近壁風速與局部流線取樣另切片。

## 驗證

尚未驗證：本機測試與合併部署後可見 Chrome 驗收待補。

預定驗收：同一 run 的壓力層顯示，0.35/1.00 讀回與前後畫面；行人面不得誤報壓力 ACK；缺圖層、待回覆、斷線時不可操作；重新合成回到 artifact 預設，原 artifact hash 不變。
