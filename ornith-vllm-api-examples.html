Ornith vLLM 受信任 LAN API 範例

  • Base URL：http://192.168.10.248:18080/v1
  • Model：Ornith-1.0-35B
  • Auth：Authorization: Bearer <YOUR_ORNITH_API_KEY>

只在目前 shell session 設定 key，不要寫入 script、Git 或 shell history。

此 HTTP endpoint 僅限隔離且受信任的 lab LAN。不得經由 Internet 或不受信任網路傳送 Bearer key；跨網路邊界時必須使用 HTTPS/TLS termination 或 secure tunnel。

Windows PowerShell

$env:ORNITH_API_KEY = [System.Net.NetworkCredential]::new("", (Read-Host "ORNITH_API_KEY" -AsSecureString)).Password
$headers = @{ Authorization = "Bearer $env:ORNITH_API_KEY" }
$modelsParams = @{
  Method = "Get"
  Uri = "http://192.168.10.248:18080/v1/models"
  Headers = $headers
}
Invoke-RestMethod @modelsParams

$body = @{
  model = "Ornith-1.0-35B"
  messages = @(@{ role = "user"; content = "用一句繁體中文回答。" })
  stream = $false
  max_tokens = 256
  temperature = 0.2
} | ConvertTo-Json -Depth 6 -Compress
$chatParams = @{
  Method = "Post"
  Uri = "http://192.168.10.248:18080/v1/chat/completions"
  Headers = $headers
  ContentType = "application/json"
  Body = $body
  TimeoutSec = 300
}
Invoke-RestMethod @chatParams
Remove-Item Env:ORNITH_API_KEY

curl（bash，單行）

curl http://192.168.10.248:18080/v1/chat/completions -H "Authorization: Bearer $ORNITH_API_KEY" -H "Content-Type: application/json" -d '{"model":"Ornith-1.0-35B","messages":[{"role":"user","content":"Reply briefly with ok."}],"stream":false,"max_tokens":256,"temperature":0}'

Python OpenAI SDK

import os
from openai import OpenAI

client = OpenAI(
    base_url="http://192.168.10.248:18080/v1",
    api_key=os.environ["ORNITH_API_KEY"],
)
response = client.chat.completions.create(
    model="Ornith-1.0-35B",
    messages=[{"role": "user", "content": "用一句繁體中文回答。"}],
    max_tokens=256,
    temperature=0.2,
)
print(response.choices[0].message.content)

常見狀態

  • 401 Unauthorized：key 缺少或不正確。
  • 連線失敗：確認主機、port 18080、防火牆與容器狀態。
  • 只有 reasoning 或 finish_reason=length：提高 max_tokens。
